Pure-Rust health-data servers built on open standards. Each product lives in
its own repository, documents itself on its own domain, and runs without the
others. The family site is <https://ferrohealth.eu>.

| Product | What it does |
|---|---|
| [FerroCHART](https://github.com/rubentalstra/FerroCHART) | an openEHR form builder and renderer · <https://ferrochart.eu> |
| [FerroEHR](https://github.com/rubentalstra/FerroEHR) | an openEHR Clinical Data Repository · <https://ferroehr.eu> |
| [FerroTERM](https://github.com/rubentalstra/FerroTERM) | an HL7 FHIR terminology server · <https://ferroterm.eu> |
| [FerroBRIDGE](https://github.com/rubentalstra/FerroBRIDGE) | a bridge from openEHR to FHIR and to the OMOP Common Data Model · <https://ferrobridge.eu> |

Planned, each with a repository and no release yet:
[FerroPIX](https://github.com/rubentalstra/FerroPIX) for patient identity,
[FerroSMART](https://github.com/rubentalstra/FerroSMART) for SMART on openEHR
authorisation, [FerroFED](https://github.com/rubentalstra/FerroFED) for
federation and [FerroSYS](https://github.com/rubentalstra/FerroSYS) as the
control plane.
